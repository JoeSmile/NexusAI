# QA — SSE 流式 [T20]

> 来源: `docs/MANUAL_TEST.md` §4。页面操作类,无脚本(需浏览器 + 网络面板观察)。
> 页面: `http://localhost:8000/playground/streaming.html`

## 用例

| # | 验证点 | 操作 | 预期 |
|---|--------|------|------|
| 4.1 | 正常流 | 页面发一条长问题 | 逐 token 出现,收尾 `[DONE]` 或完成事件 |
| 4.2 | 心跳 [T20] | 空闲等待 >15s | 网络面板出现 `: ping` 注释帧,连接不被代理掐断 |
| 4.3 | 断开中止 [T20] | 流式中途刷新/关闭页面 | 服务端日志无「残留生成」,无 500 |
| 4.4 | 错误事件协议 [T20] | 触发内容过滤 | 收到 `{"type":"error","code":"...","message":"..."}`,非裸 500/断连 |
| 4.5 | abort 按钮 | 页面 abort | 流停止,服务端停止生成 |
| 4.6 | retraction | 超长回复 | 页面展示截断/撤回逻辑 |

**通过标准:** [T20] 4.2/4.3/4.4 三项硬验收,未过则打回。

## 验证要点(页面操作)

1. 打开 streaming.html,填 key(streaming 走 `/chat/streaming`)
2. 发长问题(如「帮我总结公司知识库数据备份要点」)观察逐字输出
3. 流式中间刷新页面 → 去服务端日志确认无残留生成(asyncio.CancelledError 被捕获)
4. 发违禁诱导词 → 确认收到结构化 error 事件
5. 长空闲 >15s → DevTools Network 面板找 `: ping` 帧
